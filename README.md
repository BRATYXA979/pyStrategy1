# pyStrategy — пошаговая стратегия (десктопное приложение)

База пошаговой стратегии для двух игроков: игровое поле 8×8, поделённое на отдельные зоны
(клетки), как в шахматах — по ним в будущем будут перемещаться юниты.

Игра оформлена как **полноценное десктопное приложение** на Electron (как игры из Steam):
нативное окно без браузерного интерфейса, полноэкранный режим, горячие клавиши, сборка
установщика для Windows / Linux / macOS через electron-builder.

## Быстрый старт (desktop-приложение)

```bash
cd app
npm install     # установит Electron и electron-builder
npm start       # запуск игры в нативном окне
```

## Сборка установщика («как игра из Steam»)

```bash
cd app
npm run dist:win    # .exe-установщик (NSIS) + portable-версия  [собирать на Windows]
npm run dist:linux  # AppImage и .deb                           [собирать на Linux]
npm run dist:mac    # .dmg                                      [собирать на macOS]
```

Готовые файлы появятся в `app/dist/`.

## Управление

| Действие                | Клавиша / кнопка            |
|-------------------------|-----------------------------|
| Выбрать зону             | ЛКМ по зоне                 |
| Снять выделение          | повторный клик / `Esc`      |
| Завершить ход            | `Пробел` / кнопка «Конец хода» |
| Полный экран             | `F11` / кнопка «⛶»          |

## Что реализовано

- **Нативное окно Electron**: свой процесс main + изолированный renderer, безопасный
  preload-мост (`contextIsolation`, `sandbox`), меню браузера убрано — выглядит как игра
- **Поле 8×8** из отдельных зон с шахматной расцветкой и координатами (A1–H8)
- **Подсветка выбранной зоны** золотым свечением с анимацией пульсации
- **Подсветка соседних зон** (зелёным) — будущие направления движения юнита (8 сторон)
- **HUD как в реальных играх**: карточки двух игроков, счётчик ходов, кнопка «Конец хода»,
  нижняя панель информации о выбранной зоне
- **Ходы players**: переключение активного игрока (Игрок 1 / Игрок 2), нумерация ходов
- **Модель данных зон** (`zones[]`): у каждой зоны есть `id`, `row`, `col`, `unit`,
  `owner`, `terrain` — готова к добавлению юнитов и боевых механик
- Браузерная версия для быстрого просмотра: просто откройте `index.html` в корне

## Структура проекта

```
├── index.html            # браузерная (быстрая) версия поля
├── style.css             # стили браузерной версии
├── script.js             # логика браузерной версии
└── app/                  # десктопное приложение (Electron)
    ├── package.json      # зависимости + конфигурация electron-builder
    └── src/
        ├── main/main.js          # главный процесс: окно, полный экран, жизненный цикл
        ├── preload/preload.js    # безопасный API gameAPI для renderer
        └── renderer/             # интерфейс игры
            ├── index.html        # HUD + поле
            ├── style.css         # тёмная игровая тема, подсветка зон
            └── game.js           # модель зон, выбор/подсветка, ходы игроков
```
